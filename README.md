# Flowers Classification

A flower classification model trained on the [l3llff/flowers](https://www.kaggle.com/datasets/l3llff/flowers/code) dataset.
The dataset has 16 different classes of flowers, adding up to 15k images total.
The model uses a Convolutional Neural Network (CNN) architecture.

## Running

Open the [cvwork.ipynb](cvwork.ipynb) file in a [Google Colab](https://colab.research.google.com/) project or a [Jupyter](https://jupyter.org/try-jupyter/lab/) notebook.
